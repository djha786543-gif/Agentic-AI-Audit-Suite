# Readiness Templates

## Purpose
Provide reusable templates for Day-0 onboarding, Day-30 stabilization, and Quarterly assurance review.

## Day-0 Onboarding Template
### Objectives
- Confirm platform accessibility and role onboarding.
- Confirm minimum data source connectivity.
- Execute first scoped control cycle.

### Checklist
- Users and roles provisioned.
- Primary data sources configured and tested.
- Initial audit scope documented.
- ITGC and ITAC pilot run completed.
- Evidence traceability validated for pilot findings.
- Governance review cadence scheduled.

### Exit Criteria
- No critical setup blockers.
- Team can execute one end-to-end cycle without admin intervention.

## Day-30 Stabilization Template
### Objectives
- Move from pilot behavior to repeatable operations.
- Validate quality, ownership, and reporting discipline.

### Checklist
- Weekly governance review running on schedule.
- Exceptions include owner, due date, and rationale.
- Evidence quality checks performed each cycle.
- Reporting package accepted by leadership audience.
- UAT checks performed for any major change.

### Metrics to Track
- Control execution completion rate.
- Open critical/high findings count.
- Overdue remediation count.
- Evidence completeness ratio.

### Exit Criteria
- Operational rhythm is stable.
- Leadership receives predictable monthly pack.

## Quarterly Assurance Template
### Objectives
- Demonstrate control coverage, evidence integrity, and governance effectiveness.

### Checklist
- Scope confirmation and control inventory refresh.
- Full-cycle ITGC and ITAC execution completed.
- Risk register reviewed and reprioritized.
- Compliance evidence pack generated and verified.
- UAT/release readiness evidence attached.
- Executive summary approved.

### Deliverables
- Quarterly report package.
- Evidence pack with checksums.
- Open-risk and remediation action register.

### Exit Criteria
- Required stakeholders sign off.
- Outstanding critical items have approved action plans.
