UAT Closure Guide

1. Click Start UAT Run with small scale first to validate service stability.
2. Click Refresh Reports and open the latest report.
3. If status 0 appears in top failures, stabilize runtime first (avoid reload mode, verify DB health).
4. If 500 dominates, fix backend exceptions before tuning performance.
5. Use Compare Latest 2 Runs to confirm failed steps and 5xx counts trend downward.
6. Promote to medium/deep only after small scale is stable.
7. Close UAT when readiness gate reaches Industry Ready on at least 3 consecutive runs.
