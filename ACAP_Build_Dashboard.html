GET /api/v1/audit/runsnew Extraction run audit trail — every batch that fed the vault
GET /api/v1/health Liveness probe — returns 200 if process is alive
GET /api/v1/health/readynew Readiness probe — checks DB connectivity
GET /docs Interactive Swagger UI (development mode only)
